# LLMKube AI Security Example

This example demonstrates a conceptual approach to securing Large Language Model (LLM) interactions against manipulation attempts like prompt injection. It simulates an LLM call wrapped with a security layer, similar to how a platform like LLMKube would enforce policies to make AI systems more resilient. The security guard checks for malicious patterns before allowing the prompt to reach the LLM, preventing unauthorized actions or information disclosure.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal using `python main.py`.
